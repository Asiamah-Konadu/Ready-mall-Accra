# Ready Mall Accra 🏬🇬🇭

> **"Pizza Ready meets Accra Mall"** — An immersive 3D browser shopping arcade game featuring real Accra stores, authentic products, interactive avatar navigation, and Ghana MoMo checkout simulation.

---

## 🌟 Highlights & Features

- **🎮 3D WebGL Virtual Mall (Three.js)**: Walk or run around the mall with third-person avatar controls, interactive NPC shoppers, and smooth room navigation.
- **🏬 Distinct Themed Districts**:
  - 🏛️ **Grand Lobby**: Central hub with billboard banners, information desk, and fast-travel teleport pads.
  - 👟 **Shoe District**: Real-world vendor kiosks (e.g. Accra Kicks, Kantamanto Thrift, Osu Streetwear).
  - 📱 **Tech Alley**: Electronics & gadgets (Circle Tech Hub, Mac & iPhone stalls).
  - 🛒 **Market Bazaar**: Groceries, fresh produce, and local essentials.
  - 🍔 **Food Court**: Chop bars, jollof joints, kebabs, and smoothie bars.
  - 💳 **Cashier & Checkout Zone**: Dedicated checkout counters.
- **🛒 Dynamic Shopping & Cart System**: Interactive product showcases, item inspection, adding to cart, and inventory counter.
- **🇬🇭 Local Payment Options**: Simulated Ghana Mobile Money (MTN MoMo, Telecel Cash, AT Money) and Card checkout flows with receipts.
- **👕 Avatar Customization / Wardrobe**: Customize skin tones, apparel, hairstyles, and accessories.
- **🔊 Sound FX & Ambient Audio**: Dynamic spatial audio, shopping sound effects, and volume controls.
- **🏬 Merchant Portal**: Vendor management view for adding products and managing stall inventory.

---

## 🛠️ Tech Stack

- **Core**: Vanilla HTML5, CSS3, JavaScript (ES Modules)
- **3D Graphics Engine**: [Three.js](https://threejs.org/)
- **Bundler & Dev Server**: [Vite](https://vitejs.dev/)
- **Effects**: [canvas-confetti](https://www.npmjs.com/package/canvas-confetti)
- **Typography**: [Google Fonts (Outfit)](https://fonts.google.com/specimen/Outfit)

## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Asiamah-Konadu/Ready-mall-Accra.git
   cd Ready-mall-Accra
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview production build:
   ```bash
   npm run preview
   ```

## 🎮 Controls

| Action | Controls |
|---|---|
| **Move** | `W`, `A`, `S`, `D` or Arrow Keys / On-screen Joystick |
| **Interact / Open Stall** | `E` or Tap on stall / proximity prompt |
| **Fast Travel** | Top Navigation Bar pills |
| **Search** | Top Search Bar |
